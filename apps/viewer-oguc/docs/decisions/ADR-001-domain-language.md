# ADR-001 — Domain Language

## Status

Accepted

## Context

BWise Engine requires a consistent domain vocabulary to avoid ambiguous terminology across modules.

## Decision

The following terms are part of the official domain language:

- Project
- Model
- Element
- Selection
- Property
- View
- Camera
- Issue
- Classification
- Quantity

These names should be used consistently across the codebase.

## Consequences

Future modules should reuse this vocabulary instead of introducing synonyms.
